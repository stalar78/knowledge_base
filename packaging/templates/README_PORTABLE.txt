GPT Course Knowledge Extractor - Портативная версия
===================================================
Version: 0.1.0

Что это:
Эта папка содержит готовую портативную сборку приложения для извлечения знаний из видеокурсов.
Python устанавливать не нужно.

Как запустить:
1. Дважды кликните START_HERE.bat
или
2. Дважды кликните GPTCourseKnowledgeExtractor.exe

Обычный рабочий сценарий:
1. Создайте курс.
2. Откройте папку курса.
3. Положите видео в input/video или MP3 в input/audio.
4. При необходимости нажмите "Извлечь аудио".
5. Нажмите "Транскрибировать".
6. Нажмите "Очистить".
7. Нажмите "Создать промпты".
8. Вставьте prompt в ChatGPT вручную в браузере.
9. Сохраните ответ GPT и выполните импорт summary.
10. Нажмите "Собрать индекс".
11. Нажмите "Промпт анализа курса".
12. Нажмите "Экспорт Obsidian".

Где хранятся данные курсов:
courses\<course_slug>\

FFmpeg:
- Для извлечения MP3 из видео нужен ffmpeg.exe.
- Поместите ffmpeg.exe в: tools\ffmpeg\ffmpeg.exe
- Если ffmpeg.exe уже лежит в этой папке, дополнительных действий не требуется.
- ffmpeg.exe не хранится в Git-репозитории проекта.

Приватность и офлайн:
- Приложение обрабатывает локальные файлы на вашем компьютере.
- Шаги с ChatGPT выполняются пользователем вручную в браузере.
- В коде есть API-режим OpenAI, но для портативной сборки основной сценарий — ручной.

Что не удалять:
- config\
- tools\
- courses\
- GPTCourseKnowledgeExtractor.exe
- GPTCourseKnowledgeRunner.exe
